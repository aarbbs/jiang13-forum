# Issue 预填模板

以下可直接复制到本仓库 Issues 创建。本分支为 **SSR**（`rebuild/gitea-ssr`）；对照 SPA 请注明 `main`。

---

## Issue · Bug 模板

**标题：** `[Bug] 简短描述`

**标签：** `bug` `ui/ux`

**正文：**

### 问题描述

（一句话）

### 复现步骤

1. …
2. …

### 期望行为 / 实际行为

### 相关代码（若已知）

- 模板：`templates/…`
- 路由：`routers/web/…`
- 样式/脚本：`web_src/…`

### 环境

- 分支：`rebuild/gitea-ssr`（或 `main` SPA）
- 浏览器 / OS
