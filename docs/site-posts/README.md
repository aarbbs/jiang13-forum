# 站务公告 · 发帖素材

本目录提供「站务公告」板块的建板参数，以及可直接复制到论坛的介绍文章（Markdown）。

## 板块设置

| 项 | 建议值 |
| --- | --- |
| 名称 | 站务公告 |
| 描述 | 本站说明与姜十三论坛介绍。请勿灌水。 |
| 图标 | `megaphone` |
| 色标 | 建议第 0 或 1 槽（稳重、好辨认） |
| 排序 | `0`（尽量靠前） |

## 发布建议

1. 先建板块，再按上表顺序发帖。
2. 每篇复制「标题 / 标签 / 正文」三块；正文从 `---` 后的正文区开始粘贴。
3. 若编辑器是富文本：粘贴后检查标题层级与列表是否正常。
4. 本板块仅发站务与介绍；日常讨论放到其他板块。
